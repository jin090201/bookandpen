# 북앤펜 (BookAndPen)

책 페이지를 촬영/업로드하면 브라우저에서 바로 글자를 인식(Tesseract.js)하고,
줄바꿈을 정리한 뒤 필사 노트로 저장하는 모바일 웹입니다.
서버 없이 내 기기(LocalStorage)에만 저장됩니다.

- 바로 쓰기: https://jin090201.github.io/bookandpen/
- 저장소: https://github.com/jin090201/bookandpen
- 버전: v1.1

## 범위
- 포함: 책 등록·삭제·상태 변경, 필터·정렬(저자순 포함), 카메라/파일 이미지 업로드, 브라우저 OCR, 텍스트 후처리, 필사 저장·수정·삭제(종류: 책 문장/내 글), 즐겨찾기, 통계(일간·연간), 독서 달력(날짜별 목록·내용 내려받기), 책별 내보내기(마크다운/텍스트), 백업 내보내기·가져오기(마지막 백업 후 30일 또는 저장 공간 80% 이상이면 알림, 닫으면 7일간 백업 문구 숨김), 삭제 직후 7초간 되돌리기, 입력 한도(필사 5,000자·메모 500자·사진 10MB), 화면 설정(글자 크기·글꼴, 색 테마, 포인트 색, 표지 색·글자, 카드 수, 모서리, 점·배지), 사용 방법 안내, 모든 기록 삭제
- 제외: 온보딩, 스트릭(해빗 트래커), 목표 등록, 태그, 업데이트·공지 창, 공유 카드, 서버 동기화, 책 검색(보류)

## 문서
설계 문서는 `docs/` 폴더에 있습니다. (요구사항, 구조, 데이터, API 초안, 화면, 작업 목록)

## 실행 (Windows cmd)
```
npm install
npm run dev
```
같은 Wi-Fi의 휴대폰에서 터미널에 표시된 `Network` 주소로 접속하면 촬영 기능까지 테스트할 수 있습니다.
(카메라 촬영은 https 환경에서 가장 안정적이라, 배포 후 테스트를 권장합니다.)

## 배포 (GitHub Pages)
이 저장소는 GitHub Actions로 배포합니다. `main`에 push하면 `.github/workflows/deploy.yml`이 자동으로 빌드해 https://jin090201.github.io/bookandpen/ 에 올립니다.
(저장소 Settings → Pages → Source는 **GitHub Actions**로 설정되어 있습니다.)

## 업로드에서 제외되는 파일
`.gitignore`에 따라 아래 파일은 GitHub에 올라가지 않습니다.
- 환경 변수·키·인증서: `.env`, `*.pem`, `*.key`, `secrets/` 등
- 패키지 설정에 토큰이 들어갈 수 있는 `.npmrc`
- 내 기록이 들어 있는 백업 파일(`*backup*.json`)과 사진(`*.jpg`, `*.jpeg`, `*.png`)
- 테스트 파일과 `docs/test-spec.md`, 빌드 결과(`dist`), `node_modules`

단, `public/` 폴더 안의 이미지(아이콘·로고 등)는 예외로 제외되지 않고 올라갑니다. 다른 폴더의 이미지를 올려야 하면 `.gitignore`에 예외 한 줄을 추가합니다. (예: `!src/assets/logo.png`)

## 알아둘 점
- 처음 인식할 때 한국어/영어 언어 데이터를 내려받아 시간이 걸립니다(이후 캐시).
- LocalStorage는 용량(약 5MB)이 제한적이라 이미지는 저장하지 않고 텍스트만 저장합니다.
- 브라우저 데이터를 지우면 기록도 사라집니다. 설정 → 백업에서 JSON으로 내보내 두고, 필요할 때 가져오시기 바랍니다. (화면 설정은 백업에 포함되지 않습니다.)
