# 요구사항 (requirements.md)

> 작성: AI 초안 / 확인: 개발자(실제 사용자 요구, 기능 범위)
> 기준: 현재 코드(v1.1). 구현된 것과 아직 없는 것을 구분해 적었습니다.

## 1. 제품 한 줄 설명
책 페이지를 사진으로 찍으면 브라우저에서 글자를 인식(OCR)해 필사 노트로 저장하는 모바일 웹앱, **북앤펜(BookAndPen)**.
서버 없이 내 기기의 브라우저(LocalStorage)에만 저장합니다.

## 2. 사용자
- 책을 읽으며 마음에 드는 문장을 모아 두고 싶은 개인 사용자 (스마트폰 사용이 중심).

## 3. 사용자 스토리와 인수 조건

### 3-1. 책 관리
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| B1 | 책을 등록하고 싶다 | 제목(필수), 저자·출판사(선택)로 등록. 제목이 비면 등록 안 됨. 처음 상태는 "읽는 중" | 구현 |
| B2 | 책 상태를 바꾸고 싶다 | 읽고 싶은 / 읽는 중 / 완독 / 중단 중 선택. 완독으로 바꾼 날짜(`completed_at`)를 저장 | 구현 |
| B6 | 책 제목·저자·출판사를 잘못 써서 고치고 싶다 | 책 상세의 "책 정보 수정" 행: 제목(필수)·저자·출판사를 그 자리에서 고치고 저장·취소. 필사·즐겨찾기는 책 번호로 이어져 그대로 유지, 검색·달력·통계의 책 제목도 함께 바뀜 | 구현 |
| B7 | 책과 필사를 한 번에 찾고 싶다 | 책장의 검색 칸 하나로 책 제목·저자·출판사와 필사 본문·메모 검색(띄어쓰기·대소문자 무시), 범위 칩(전체·책·필사, 개수 표시), 책·필사 구역, 필사 미리보기 3개와 모두 보기, 최근 검색어(최대 5개, 이 기기에만 저장·백업 제외), 검색어 유지 | 구현 |
| B8 | 이 책을 언제부터 읽었는지 보고 싶다 | 책 상세의 읽기 기간 한 줄: 첫 필사 날짜, 완독일(완독일 때), 필사 개수, 마지막 필사 날짜 | 구현 |
| B9 | 책장을 한눈에 정리해서 보고 싶다 | 상태 칩(개수 포함, 한 줄 가로 스크롤)과 표지형·목록형 보기 전환(선택 저장). 목록형은 제목 두 줄·저자·상태·필사 개수·마지막 필사 날짜를 보여 줌 | 구현 |
| T10 | 필사를 다른 앱으로 보내고 싶다 | 책 상세의 "공유": 기기 공유 창으로 필사 보내기(선택 모드 지원), 미지원 브라우저는 "복사" | 구현 |
| B3 | 책을 정렬·거르고 싶다 | 상태 칩(개수 포함)으로 거르기, 최근 필사순·등록순·제목순·저자순·필사 많은 순 | 구현 |
| B4 | 책을 정리하고 싶다 | 편집 모드에서 여러 권 선택(전체 선택 가능) 후 삭제(그 책의 필사도 함께 삭제, 확인 창 표시) | 구현 |
| B5 | 책 사진 대신 표지 느낌으로 보고 싶다 | 제목 기반 파스텔 표지 카드(색 계열·밝기·글자 방식 설정 가능) | 구현 |

### 3-2. 필사
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| T1 | 사진으로 필사하고 싶다 | 카메라 촬영 또는 사진 불러오기 → 글자 인식(한국어+영어) → 줄바꿈 정리 → 편집 가능한 텍스트 | 구현 |
| T2 | 인식 오류를 고치고 싶다 | 인식 결과를 직접 수정, 후처리 다시 적용 가능, 직접 입력도 가능 | 구현 |
| T3 | 필사에 부가 정보를 달고 싶다 | 종류(책 문장 / 내 글, 둘 다 선택 가능, 선택 안 하면 미분류), 페이지 번호, 메모 | 구현 |
| T4 | 필사를 수정·삭제하고 싶다 | 필사별 수정, 삭제, 책 단위로 필사 전체 삭제 | 구현 |
| T5 | 필사를 종류별로 보고 싶다 | 전체/책 문장/내 글/미분류 필터, 목록 나누기(5개씩) | 구현 |
| T6 | 필사를 복사·내보내고 싶다 | 필사별 복사, 책별 마크다운/텍스트 내보내기 | 구현 |
| T7 | 사진에서 필사할 부분만 인식하고 싶다 | 사진을 고르면 자르기 화면에서 영역을 골라 "이 부분으로 인식", 또는 "자르지 않고 인식". 자른 이미지는 저장하지 않음. 인식 뒤 미리보기에는 고른 부분만 보임. 모서리·영역은 방향키(Shift는 크게)로도 움직일 수 있음 | 구현 |
| T8 | 새 사진의 글자를 어떻게 넣을지 고르고 싶다 | 내용이 있을 때 "아래에 이어 붙이기"(기본)/"바꾸기" 선택, 전체 지우기 | 구현 |
| T9 | 잘못 읽었을 만한 글자를 찾고 싶다 | 인식 직후 신뢰도 70 미만 단어를 "확인" 칩으로 표시, 누르면 본문에서 선택. 고쳐서 본문에서 사라진 단어는 목록에서 빠짐. 비슷한 글자로 바뀐 한글 오류는 표시되지 않음. 기호·한 글자 한글은 제외하고, 사진 한 장에서 11개 이상이면 그 사진의 칩은 만들지 않고 다시 찍기 안내(앞서 만든 칩은 유지) | 구현 |

### 3-3. 즐겨찾기
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| F1 | 마음에 든 문장을 모아 보고 싶다 | 필사의 ☆를 누르면 ★, 즐겨찾기 탭에 최신순으로 5개씩 모임(긴 글은 4줄까지, "더 보기") | 구현 |
| F2 | 즐겨찾기를 한꺼번에 해제하고 싶다 | 선택 모드에서 여러 개 해제(필사 내용은 유지) | 구현 |

### 3-4. 설정·백업
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| S1 | 글자를 크게 보고 싶다 | 글자 크기 4단계, 화면 글꼴 3종, 필사 본문 글꼴 5종(손글씨 포함) | 구현 |
| S2 | 화면 분위기를 바꾸고 싶다 | 색 테마(라이트·다크·세피아·기기 설정), 포인트 색(먹색·보라·파랑) | 구현 |
| S3 | 책장 모양을 바꾸고 싶다 | 표지 색 계열, 밝기 3단계, 표지 글자(제목 전체·제목+저자·없음), 한 줄 카드 수, 모서리, 회색 점·상태 배지 표시 | 구현 |
| S4 | 기록을 잃고 싶지 않다 | 백업 파일(JSON) 내보내기, 가져오기(가져오기 전에 새로 들어오는 수·건너뛰는 수·백업 만든 날을 요약해 보여 주고 확인받음, 이미 있는 기록은 건너뜀, 값이 빠졌거나 형식이 틀린 항목은 고쳐서 받음, 없는 날짜·겹치는 id·알 수 없는 종류 값도 바로잡고 본문이 빈 필사는 받지 않음) | 구현 |
| S5 | 사용법을 알고 싶다 | 설정 탭의 "사용 방법"(12개 항목, 굵은 글씨·팁·주의 상자), 빈 책장 안내 | 구현 |
| S9 | 어떤 파일을 가져올 수 있는지 알고 싶다 | 사용 방법 11번과 가져오기 버튼 아래 안내. 북앤펜 백업(.json)만 가능, 읽기용 문서·필사에서 내려받은 .md·.txt와 다른 앱 파일은 "읽기용이라 불러올 수 없다"는 안내와 함께 거절. 설정의 읽기용 문서 구역과 사용 방법 6번에도 "읽고 공유하는 용도, 보관은 백업"이라고 안내 | 구현 |
| S6 | 기록을 모두 지우고 싶다 | 설정 > 데이터의 "모든 기록 삭제"(확인 창 두 번) | 구현 |
| S7 | 개인정보·저작권·라이선스를 알고 싶다 | 설정 > 정보: 개인정보 안내, 저작권 안내(옮겨 적은 글의 저작권은 저자·출판사에 있고 필사는 개인 감상용, 공유 때는 출처 표시), 오픈소스 라이선스. 핵심 문구는 굵게, 팁·주의는 상자로 구분 | 구현 |
| S8 | 백업 알림을 귀찮지 않게 받고 싶다 | 마지막 백업 후 30일 또는 백업 이력이 없으면 책장 위에 띠 표시. ✕로 닫으면 7일간 숨김. 저장 공간 80% 이상 경고는 숨기지 않음 | 구현 |

### 3-5. 기록 (통계·달력)
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| R1 | 오늘 얼마나 필사했는지 보고 싶다 | 일간 통계: 종류 필터, 한 주 날짜 줄, 제목을 눌러 연·월 고르기(미래 달은 이동 불가), 선택한 날의 필사 수·글자 수·완독한 책·목록(긴 글은 "더 보기", 5개씩 나눔) | 구현 |
| R2 | 한 해를 돌아보고 싶다 | 연간 통계: 1년 동안, 월 평균(완독 권수), 가장 많이 필사한 달, 월별 막대(달을 누르면 월간 통계로 이동), 제목을 눌러 연도 고르기(올해 기준 과거 5년과 올해, 미래 연도는 이동 불가) | 구현 |
| R3 | 읽은 날을 한눈에 보고 싶다 | 독서 달력: 필사 1·2·3개 이상에 따라 날짜 진하기(또는 점), 제목을 눌러 연·월 고르기(미래 달은 이동 불가), 책을 완독한 날은 ✓ 표시, 날짜를 누르면 그날 목록과 완독한 책 | 구현 |
| R4 | 달력 내용을 파일로 받고 싶다 | 설정 → 데이터의 "읽기용 문서로 내려받기"(달력 화면에는 버튼을 두지 않음): 범위 전체·올해·이번 달·직접 고르기(월 단위), 마크다운/텍스트, 날짜별로 묶음(완독한 날은 "✓ 완독: 제목" 한 줄과 요약의 완독 권수 포함, 완독만 한 날도 날짜 항목으로 넣음) | 구현 |
| R5 | 달력을 내 방식으로 보고 싶다 | 달력 설정: 한 주 시작(일/월), 표시(진하기/점), 범위, 형식 | 구현 |
| R6 | 모아 둔 문장을 다시 찾고 싶다 | 책장의 검색 칸(B7)의 "필사" 범위: 모든 책의 필사 본문·메모 검색, 찾은 글자 강조, 종류 필터, 결과 개수, 목록 나누기, 누르면 책 상세로 이동 | 구현 |
| R7 | 한 달을 돌아보고 싶다 | 월간 통계: 종류 필터, 연·월 고르기(미래 달은 이동 불가), 이 달 필사·글자 수·필사한 날·완독한 책, 가장 많이 필사한 날, 날짜별 막대(누르면 그날의 일간 통계로 이동) | 구현 |
| R8 | 지난 필사를 읽은 날에 맞춰 넣고 싶다 | 필사 추가·수정의 "기록한 날": 기본값은 오늘(수정은 원래 날짜), 오늘까지만 선택, 시각은 유지. 며칠에 걸친 필사는 날마다 나눠 저장하도록 안내(기간 저장은 하지 않음) | 구현 |
| R10 | 책을 얼마나 읽었는지 보고 싶다 | 책 정보에 전체 페이지 수(선택)를 적으면 책 상세에 진행률 막대와 "읽은 페이지 / 전체 페이지 · %"(읽은 쪽 = 그 책 필사에 적은 가장 큰 페이지), 책장 목록형에 얇은 막대. 완독 100%, 중단 회색, 전체보다 큰 페이지는 100%와 안내, 전체 페이지 수를 안 적은 책은 막대 없음 | 구현 |
| R9 | 올해 몇 권을 읽을지 정하고 싶다 | 통계 위쪽 "올해 완독 목표" 카드: 목표 권수(1~999) 정하기·고치기·없애기, 올해 완독한 책 수와 진행 막대, 목표를 이루면 "목표를 이뤘어요!". 목표는 백업에 포함, 가져오기에서는 없는 해만 추가 | 구현 |

통계 기준은 필사 수·글자 수·완독한 책 권수입니다(독서 시간은 기록하지 않음). 완독 권수는 통계 위 카드·올해 완독 목표·월간·연간 모두 완독 날짜(`completed_at`)가 저장된 책만 셉니다(날짜가 없는 완독 책은 어디에도 세지 않으며, 책 상태는 그대로 완독으로 보입니다).

### 3-6. 우선순위 (제안)
위 스토리를 앱의 핵심 여부로 나눈 제안입니다. 필수는 없으면 앱의 목적(사진으로 필사 기록)이 성립하지 않는 것, 권장은 있으면 쓰기 훨씬 편한 것, 선택은 꾸미기·보기 편의입니다.

| 우선순위 | 스토리 |
|---|---|
| 필수 | B1 책 등록, B2 책 상태, B6 책 정보 수정, B7 책 검색, B8 읽기 기간, B9 책장 칩·목록형, T1 사진으로 필사, T2 인식 오류 고치기, T3 부가 정보, T4 수정·삭제, S4 백업 |
| 권장 | B3 정렬·필터, B4 책 정리, T5 종류별 보기, T6 복사·내보내기, T7 부분 인식, T8 이어 붙이기·바꾸기, T9 확인 칩, T10 공유, F1·F2 즐겨찾기, S1 글자 크기, S2 색 테마, S5 사용 방법, S6 모든 기록 삭제, S7 정보, S8 백업 알림, R1 일간 통계, R3 독서 달력, R6 필사 검색, R8 기록한 날 |
| 선택 | B5 표지 카드, S3 책장 모양, R2 연간 통계, R7 월간 통계, R9 올해 완독 목표, R4 읽기용 문서 내려받기, R5 달력 설정 |

## 4. 비기능 요구사항
- **저장**: 브라우저 LocalStorage만 사용. 이미지는 저장하지 않고 텍스트만 저장(용량 약 5MB 제한).
- **개인정보**: 서버로 보내는 데이터 없음. 사진은 브라우저 안에서만 처리. 다만 글꼴(Google Fonts)과 글자 인식 엔진·언어 데이터(jsdelivr)는 인터넷에서 내려받으며, 이때 기록·사진은 보내지 않지만 해당 서비스에 접속 기록이 남을 수 있음(설정 > 정보에 안내).
- **환경**: 모바일 브라우저 우선, 최대 너비 약 448px(max-w-md) 한 칸 레이아웃.
- **네트워크**: 첫 글자 인식 때 엔진과 언어 데이터를 내려받음(이후 브라우저 캐시). 구글 폰트도 인터넷이 있어야 내려받고, 없으면 시스템 글꼴로 표시.
- **성능·용량**: 사진은 긴 변 2800px까지만 줄여 인식하고(작은 사진은 키우지 않음), 사진 10MB·필사 5,000자·메모 500자를 넘으면 받지 않고, 책 제목 100자·저자 50자·출판사 50자는 입력칸에서 더 입력되지 않음. 첫 인식은 내려받는 시간 때문에 오래 걸리며 화면에 안내를 표시함. 번들 크기는 약 230KB(압축 약 77KB)임(v1.1 빌드 기준).
- **보안**: 서버·인증 정보 없음. 배포본에는 CSP(콘텐츠 보안 정책)를 적용해 허용한 주소(자기 자신, cdn.jsdelivr.net, Google Fonts) 외의 스크립트·연결을 막음. 자세한 내용은 architecture.md 6장.
- **접근성**: 글자 크기 설정, 입력창 글자 크기 16px 이상(iOS 자동 확대 방지), 자르기 화면은 방향키로도 조작 가능.
- **배포**: GitHub Pages(GitHub Actions)로 정적 배포. 절차는 deployment.md.

온보딩, 스트릭(해빗 트래커), 책별 목표일·하루 필사 목표, 태그·태그 통계, 주간 통계, 업데이트·공지 창(보류), 공유 카드, 서버 동기화·로그인, 책 검색 API(보류), 이미지 저장.
