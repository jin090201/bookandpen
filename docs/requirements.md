# 요구사항 (requirements.md)

> 작성: AI 초안 / 확인: 개발자(실제 사용자 요구, 기능 범위)
> 기준: 현재 코드(0.1.0). 구현된 것과 아직 없는 것을 구분해 적었습니다.

## 1. 제품 한 줄 설명
책 페이지를 사진으로 찍으면 브라우저에서 글자를 인식(OCR)해 필사 노트로 저장하는 모바일 웹앱, **북앤펜(BookAndPen)**.
서버 없이 내 기기의 브라우저(LocalStorage)에만 저장합니다.

## 2. 사용자
- 책을 읽으며 마음에 드는 문장을 모아 두고 싶은 개인 사용자 (스마트폰 사용이 중심).

## 3. 사용자 스토리와 인수 조건

### 3-1. 책 관리
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| B1 | 책을 등록하고 싶다 | 제목(필수), 저자(선택)로 등록. 제목이 비면 등록 안 됨. 처음 상태는 "읽는 중" | 구현 |
| B2 | 책 상태를 바꾸고 싶다 | 읽고 싶은 / 읽는 중 / 완독 / 중단 중 선택. 완독으로 바꾼 날짜(`completed_at`)를 저장 | 구현 |
| B3 | 책을 정렬·거르고 싶다 | 상태별 필터, 최근 필사순·등록순·제목순·저자순·필사 많은 순 | 구현 |
| B4 | 책을 정리하고 싶다 | 편집 모드에서 여러 권 선택(전체 선택 가능) 후 삭제(그 책의 필사도 함께 삭제, 확인 창 표시) | 구현 |
| B5 | 책 사진 대신 표지 느낌으로 보고 싶다 | 제목 기반 파스텔 표지 카드(색 계열·밝기·글자 방식 설정 가능) | 구현 |

### 3-2. 필사
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| T1 | 사진으로 필사하고 싶다 | 카메라 촬영 또는 사진 불러오기 → 글자 인식(한국어+영어) → 줄바꿈 정리 → 편집 가능한 텍스트 | 구현 |
| T2 | 인식 오류를 고치고 싶다 | 인식 결과를 직접 수정, 후처리 다시 적용 가능, 직접 입력도 가능 | 구현 |
| T3 | 필사에 부가 정보를 달고 싶다 | 종류(책 문장 / 내 글, 둘 다 선택 가능, 선택 안 하면 미분류), 페이지 번호, 메모 | 구현 |
| T4 | 필사를 수정·삭제하고 싶다 | 필사별 수정, 삭제, 책 단위로 필사 전체 삭제 | 구현 |
| T5 | 필사를 종류별로 보고 싶다 | 전체/책 문장/내 글/미분류 필터, 목록 나누기(3개씩) | 구현 |
| T6 | 필사를 복사·내보내고 싶다 | 필사별 복사, 책별 마크다운/텍스트 내보내기 | 구현 |

### 3-3. 즐겨찾기
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| F1 | 마음에 든 문장을 모아 보고 싶다 | 필사의 ☆를 누르면 ★, 즐겨찾기 탭에 최신순으로 모임 | 구현 |
| F2 | 즐겨찾기를 한꺼번에 해제하고 싶다 | 선택 모드에서 여러 개 해제(필사 내용은 유지) | 구현 |

### 3-4. 설정·백업
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| S1 | 글자를 크게 보고 싶다 | 글자 크기 4단계, 화면 글꼴 3종, 필사 본문 글꼴 5종(손글씨 포함) | 구현 |
| S2 | 화면 분위기를 바꾸고 싶다 | 색 테마(라이트·다크·세피아·기기 설정), 포인트 색(먹색·보라·파랑) | 구현 |
| S3 | 책장 모양을 바꾸고 싶다 | 표지 색 계열, 밝기 3단계, 표지 글자(제목 전체·제목+저자·없음), 한 줄 카드 수, 모서리, 회색 점·상태 배지 표시 | 구현 |
| S4 | 기록을 잃고 싶지 않다 | 백업 파일(JSON) 내보내기, 가져오기(이미 있는 기록은 건너뜀) | 구현 |
| S5 | 사용법을 알고 싶다 | 설정 탭의 "사용 방법", 빈 책장 안내 | 구현 |
| S6 | 기록을 모두 지우고 싶다 | 설정 > 데이터의 "모든 기록 삭제"(확인 창 두 번) | 구현 |
| S7 | 개인정보·라이선스를 알고 싶다 | 설정 > 정보: 개인정보 안내, 오픈소스 라이선스 | 구현 |

### 3-5. 기록 (통계·달력)
| ID | 스토리 | 인수 조건 | 상태 |
|---|---|---|---|
| R1 | 오늘 얼마나 필사했는지 보고 싶다 | 일간 통계: 종류 필터, 한 주 날짜 줄, 선택한 날의 필사 수·글자 수·목록 | 구현 |
| R2 | 한 해를 돌아보고 싶다 | 연간 통계: 1년 동안, 월 평균(완독 권수), 가장 많이 필사한 달, 월별 막대 | 구현 |
| R3 | 읽은 날을 한눈에 보고 싶다 | 독서 달력: 필사 1·2·3개 이상에 따라 날짜 진하기(또는 점), 날짜를 누르면 그날 목록 | 구현 |
| R4 | 달력 내용을 파일로 받고 싶다 | 달력의 "내려받기": 보는 달만/전체, 마크다운/텍스트, 날짜별로 묶음 | 구현 |
| R5 | 달력을 내 방식으로 보고 싶다 | 달력 설정: 한 주 시작(일/월), 표시(진하기/점), 범위, 형식 | 구현 |

통계 기준은 필사 수·글자 수·완독한 책 권수입니다(독서 시간은 기록하지 않음). 완독 권수 중 연도별 집계는 완독 날짜가 저장된 책만 포함합니다.

## 4. 비기능 요구사항
- **저장**: 브라우저 LocalStorage만 사용. 이미지는 저장하지 않고 텍스트만 저장(용량 약 5MB 제한).
- **개인정보**: 서버로 보내는 데이터 없음. 사진은 브라우저 안에서만 처리.
- **환경**: 모바일 브라우저 우선, 최대 너비 약 448px(max-w-md) 한 칸 레이아웃.
- **네트워크**: 첫 글자 인식 때 언어 데이터를 내려받음(이후 브라우저 캐시). 구글 폰트도 인터넷이 있어야 내려받고, 없으면 시스템 글꼴로 표시.
- **접근성**: 글자 크기 설정, 입력창 글자 크기 16px 이상(iOS 자동 확대 방지).
- **배포**: GitHub Pages(GitHub Actions)로 정적 배포.

## 5. 범위 밖 (현재 하지 않음)
온보딩, 스트릭(해빗 트래커), 목표 등록, 태그·태그 통계, 주간 통계, 업데이트·공지 창(보류), 공유 카드, 서버 동기화·로그인, 책 검색 API(보류), 이미지 저장.
