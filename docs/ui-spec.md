# 화면 명세 (ui-spec.md)

> 작성: AI 초안 / 확인: 개발자(사용성, 접근성, 화면 요구사항)

## 1. 화면 흐름
```
하단 탭 ── 책장 ──(책 선택)── 책 상세 ──(📷 필사 추가하기 / 필사 수정)── 필사 추가·수정
       ├─ 즐겨찾기 (★ 모음, 선택 모드로 여러 개 해제)
       ├─ 기록 (달력 · 통계)
       └─ 설정 (글자 설정 · 화면 구성 편집 · 데이터 · 정보 · 사용 방법)
```
상세·필사 화면에서는 하단 탭이 숨겨지고, "← 책 목록"(상세) 또는 "← 취소"(필사)로 한 단계 돌아가거나 "첫 화면"으로 책장에 바로 돌아갑니다. 폰의 뒤로가기(브라우저 뒤로 버튼)도 같은 한 단계 뒤로 가기이며, 사이트를 떠나지 않습니다. 필사 화면에서 쓰던 내용이 있으면(수정은 바뀐 것이 있을 때) "← 취소", "첫 화면", 뒤로가기 모두 "쓰던 내용이 사라져요. 저장하지 않고 나갈까요?" 확인 창을 거칩니다.
하단 탭은 선택한 탭만 아이콘이 또렷하고 글자가 굵으며, 선택하지 않은 탭은 아이콘을 흐리게(투명도 40%) 보여 줍니다.
빈 화면 안내는 EmptyState 한 곳에서 흰 카드(테두리·둥근 모서리)로 보여 줍니다. 화면에 이미 상태(부제·개수)가 보이면 할 일 한 줄만(즐겨찾기 "책의 필사 옆 ☆를 눌러 보세요.", 책 상세 "아래 버튼으로 책 페이지를 찍어 보세요."), 알려 줄 할 일이 없으면 상태 한 줄(달력 "이 날은 필사한 글이 없어요.", 책 상세 "이 종류의 필사가 없어요."), 검색은 상태와 할 일 두 줄("찾는 책이 없어요." / "다른 글자로 찾아 보세요.")입니다. 한 줄은 연한 일반 글씨, 두 줄은 첫 줄만 조금 진하게 보여 줍니다. 필사 검색(전체 보기)은 결과가 0개이면 "N개 찾았어요." 줄을 숨깁니다.
책장 화면 위에는 백업 알림 띠가 필요할 때만 표시됩니다. ✕로 닫으면 7일 동안 백업 문구가 숨겨지고, 저장 공간 80% 이상 경고는 닫을 수 없이 계속 표시됩니다(경고만 있을 때는 ✕가 없습니다). 삭제 직후에는 10초 동안 "되돌리기" 안내가 아래쪽에 표시됩니다. 삭제는 최대 5개까지 쌓이며 각각 삭제한 때부터 10초 동안만 되돌릴 수 있습니다. 안내에는 가장 최근에 삭제한 것의 문구가 보이고, 2개 이상 쌓이면 "필사를 삭제했어요. · 삭제 3건"처럼 건수가 붙으며, "되돌리기"를 누를 때마다 가장 최근 것부터 한 개씩 되돌립니다. 모든 기록 삭제를 하면 쌓인 되돌리기도 함께 지웁니다. 삭제 확인 창에도 "삭제한 뒤 10초 안에는 되돌릴 수 있어요"라고 안내하며(필사 하나, 필사 전체, 책, 선택한 책), 되돌리기가 없는 "모든 기록 삭제"만 "되돌릴 수 없어요"라고 안내합니다.

## 2. 화면별 구성

### 책장
- 상단: 앱 이름, "+ 책 등록", "편집", 안내 문구
- 등록 폼(열었을 때): 제목(필수), 저자, 출판사(선택), "등록하기". 제목과 저자가 모두 같은 책이 이미 있으면(대소문자·앞뒤 공백 무시, 저자가 비어 있는 쪽이 있으면 제목만 같아도, 저자는 한쪽이 다른 쪽을 포함하면 같은 저자로 봄, 출판사가 두 책 모두 있고 서로 다르면 다른 판본으로 보고 묻지 않음) "같은 책이 이미 있어요. 그래도 추가할까요?" 확인창을 띄우고, 취소하면 등록하지 않습니다(재독·다른 판본은 허용). 책 정보 수정에는 적용하지 않습니다.
- 검색 칸(책이 1권 이상일 때 표시, "제목·저자·출판사·필사 내용에서 찾기"): 책 제목·저자·출판사와 필사 본문·메모를 한 칸에서 찾습니다. 띄어쓰기와 대소문자는 구분하지 않고(예: "도구사용"으로 "도구 사용"을 찾음) ✕로 지웁니다. 검색어를 입력하면 칸 아래에 범위 칩(전체 · 책(제목·저자·출판사) N · 필사 N, 숫자는 결과 개수)이 나타납니다. 책이 제목이 아니라 저자나 출판사 때문에 걸리면 걸린 이유가 보이도록, 표지형에서는 카드 아래에 "저자: …"(또는 "출판사: …") 줄을 보여 주고 목록형에서는 저자 줄과 출판사 줄에서 찾은 글자를 노란색으로 강조합니다(제목에 검색어가 있으면 이유 줄을 보여 주지 않음).
  - 전체: "책 (N)" 구역에 책 결과(상태 칩·정렬·표지형/목록형 보기 적용)가 나오고, 그 아래 "필사 (N)" 구역에 필사가 3개까지 미리 보이며 "모두 보기 ›"를 누르면 필사 범위로 바뀝니다. 필사 결과는 찾은 글자를 노란색으로 강조하고 본문이 길면 찾은 글자 주변만 보이며 메모에서 찾은 글자도 보입니다. 필사 항목의 책 이름을 누르면 그 책 상세로 이동합니다.
  - 책: 책 결과만 보이고 상태 칩·정렬·보기 전환을 쓸 수 있습니다.
  - 필사: 필사 결과만 종류 필터(전체·책 문장·내 글·미분류)와 "N개 찾았어요" 개수, 5개씩 목록 나누기로 보이며 상태 칩·정렬·보기 전환은 숨깁니다.
  - 결과가 없으면 구역마다 "찾는 책이 없어요" / "찾는 필사가 없어요"가 나옵니다. 편집 모드에서는 범위 칩과 필사 구역이 사라지고 책 결과만 보입니다.
  - 검색어·범위·필사 종류 필터는 앱을 열어 둔 동안 책 상세에 다녀오거나 다른 탭을 눌렀다 와도 유지되고(필사 목록 번호는 1번으로 돌아감), 검색어를 모두 지우면 범위와 종류가 처음으로 돌아갑니다.
  - 최근 검색어: 검색 칸을 눌렀고 아직 입력이 없을 때 최대 5개가 칩(각 칩에 ✕)과 "모두 지우기"로 보입니다. 칩을 누르면 그 검색어로 찾습니다. 키보드의 검색(엔터)을 누르거나 결과를 눌러 이동할 때만 저장하며(입력 도중에는 저장하지 않음), 같은 검색어는 맨 앞으로 옮기고 5개를 넘으면 오래된 것부터 지웁니다. 이 기기에만 저장되고 백업에는 포함하지 않으며 "모든 기록 삭제"에서 함께 지워집니다.
- 상태 칩(전체·읽고 싶은·읽는 중·완독·중단, 각 개수): 한 줄로 늘어놓고 넘치면 옆으로 밀어서 보며 선택한 칩은 포인트 색입니다. 그 아래 줄에 정렬(최근 필사순·등록순·제목순·저자순·필사 많은 순)과 오른쪽에 보기 전환 [▦ 표지형][☰ 목록형]이 있고, 선택은 화면 설정에 저장됩니다(값이 없으면 표지형).
- 책 카드(한 줄 2~3열): 파스텔 표지, 회색 점(3일 안에 필사한 책), 상태 배지, 필사 개수·마지막 필사(표지형은 "오늘 / N일 전"을 달력·통계와 같은 날짜 기준으로 세므로, 밤늦게 쓴 필사도 날짜가 바뀌면 "1일 전"으로 보임)
- 목록형 보기: 한 줄에 한 권. 왼쪽에 작은 표지(표지 색 설정을 따르고 글자는 제목의 첫 글자만, 회색 점 포함), 오른쪽에 제목(두 줄까지, 넘으면 끝을 "…"), 저자(없으면 "저자 미입력"), 상태 배지와 "필사 N개 · 마지막 11.19"(올해가 아니면 "2025.12.03", 필사가 없으면 "필사 없음")를 보여 줍니다. 항목을 누르면 책 상세로 이동하고, 편집 모드에서는 왼쪽에 체크 칸이 생깁니다. "한 줄 카드 수"와 "표지 글자" 설정은 표지형에만 적용됩니다.
- 표지 글자: 제목 전체 / 제목 + 저자 / 없음. 없음이면 표지 아래에 제목 표시
- 편집 모드: 카드를 눌러 선택(체크 표시), "전체 선택/전체 해제" 줄, 하단 "선택한 책 N권 삭제"(확인 창)
- 빈 상태: "첫 책을 등록해 보세요" 안내와 "+ 책 등록" 버튼, 3단계 안내(책 등록 › 사진 찍기 › 고쳐서 저장)

### 책 상세
- 위쪽: "← 책 목록"(책장으로), "첫 화면"(책장으로 바로 이동)
- 책 정보(제목, 저자 · 출판사 한 줄)를 크게 보여 주고(출판사가 없으면 저자만, 길면 "…"로 줄임), 그 아래 작은 글씨로 읽기 기간 한 줄을 보여 줍니다(예: "2026.11.19 시작 · 필사 4개 · 마지막 2026.11.19", 완독이면 "시작 · 완독일 · 필사 N개", 필사가 없으면 이 줄을 보여 주지 않고 아래 "필사 노트 (0)"과 안내 카드가 대신 알려 줌. 시작은 첫 필사 날짜이며 저장값이 아니라 필사 날짜에서 계산함). 그 아래 한 덩어리의 행 목록을 둡니다. 행은 위에서부터 "독서 상태 [읽는 중 ›]"(행 전체를 누르면 기기의 선택 창이 열림)와 "책 정보 수정 ›"(누르면 제목 자리에서 제목·저자 입력칸과 "취소"·"저장"이 열리고, 열려 있는 동안 이 행은 숨김, 제목은 비울 수 없음), 이어서 삭제 행들입니다. 수정해도 필사는 그대로 이어지며 표지 색 "책마다"일 때는 제목에 따라 색이 달라질 수 있습니다. 이어서 필사 종류 필터, 필사 카드(본문, 메모, 종류, 페이지, ☆/★, 복사, 수정·삭제), 목록 나누기, 내보내기(.md·.txt, "공유")가 있습니다. "공유"는 폰에서 기기의 공유 창을 열어 필사를 글로 보내고(선택 모드에서는 고른 필사만), 공유 기능이 없는 브라우저에서는 "복사"로 바뀌어 클립보드에 담습니다. 행 목록의 아래쪽에 "필사 전체 삭제"(필사가 있을 때만)와 "책 삭제"가 빨간 글씨 행으로 이어지며, 두 삭제 모두 확인 창을 거치고, 삭제한 직후 10초 동안 "되돌리기"가 나옵니다.
- 하단 고정 버튼: "📷 필사 추가하기"

### 필사 추가·수정
- "📷 카메라로 촬영", "🖼 사진 불러오기" → **인식할 부분 고르기 화면**(아래) → 진행 막대(글자 인식 중 / 언어 데이터 불러오는 중). 진행 막대 줄 오른쪽에 "인식 취소" 버튼이 있어 누르면 인식 엔진을 꺼서 바로 멈추고(다음 인식 때 엔진을 새로 켬, 언어 데이터는 캐시), 연한 회색 글씨 "인식을 취소했어요."와 "다시 고르기"·"직접 입력하기" 버튼이 나옵니다. 적어 둔 본문·메모는 그대로 두고, 인식 중에 "← 취소"·"첫 화면"·뒤로가기로 화면을 나가면 인식도 함께 멈춥니다.
- 인식 오류 안내(빨간 글씨, 문장마다 줄바꿈): "글자를 찾지 못했어요. / 고른 부분이 너무 작지 않은지 확인하거나, 더 밝고 선명하게 다시 찍어 보세요."는 아래에 "다시 고르기"(방금 고른 사진으로 인식할 부분 고르기 화면을 다시 엶)와 "직접 입력하기"(오류를 지우고 필사 내용 입력칸으로 커서를 옮김) 버튼이 나오고, "인식에 실패했어요(인터넷 연결 확인, 인터넷이 안 될 때는 직접 입력해서 적을 수 있다는 안내)"에도 같은 두 버튼, "이 사진을 열 수 없어요"와 "사진이 너무 커요"에는 "직접 입력하기"만 나옵니다.
- 인식할 부분 고르기 화면: 위쪽 "← 취소"(사진을 버리고 필사 추가 화면으로), 사진 위의 네모(처음에는 사진 전체). 모서리 4곳을 끌면 크기가, 안쪽을 끌면 위치가 바뀜(마우스·터치 모두). 아래에 "사진 전체로 되돌리기", "이 부분으로 인식하기"(전체를 골랐으면 "이 사진으로 인식하기"), "자르지 않고 인식하기". 고른 부분만 인식하며 자른 이미지는 저장하지 않습니다.
- 위쪽: "← 취소"(책 상세로), "첫 화면"(책장으로). 쓰던 내용이 있으면 두 버튼과 폰 뒤로가기 모두 "쓰던 내용이 사라져요. 저장하지 않고 나갈까요?" 확인 창을 거칩니다.
- 사진 팁("💡 팁" 상자, 두 줄): 밝은 곳에서 필사할 부분이 크게 나오게 정면으로 / 인식이 안 맞을 때나 자세한 방법은 설정의 "사용 방법" 참고. 페이지 숫자·머리글은 자르기에서 빼기, 글자 복사 기능 안내는 사용 방법 2번 항목의 "팁" 줄에 있음(상자는 공통 조각 `Note.jsx`, 줄바꿈은 `whitespace-pre-line`)(필사 중 화면을 벗어나면 작성 내용이 사라지므로 촬영 요령은 화면에 둠)
- 종류 칩(책 문장 · 내 글, 둘 다 켜기 가능, 안 켜면 미분류) 오른쪽에 페이지 칸(숫자만, 최대 5자리)
- 새 사진의 글자 처리: 본문에 내용이 있을 때만 사진 버튼 아래에 "새 사진의 글자는 [아래에 이어 붙이기] [바꾸기]" 칩이 나타납니다. 기본은 이어 붙이기이고 화면을 열 때마다 이어 붙이기로 시작합니다(선택은 저장하지 않음). 바꾸기를 고른 채 사진을 올리면 "필사 내용이 새 사진의 글자로 바뀌어요. 계속할까요?" 확인 창이 뜨고, 취소하면 인식하지 않습니다. 글자를 찾지 못한 사진은 기존 내용을 건드리지 않습니다.
- 확인 목록(아래에 "⚠ 주의" 상자로 "글자 하나가 비슷한 글자로 바뀐 경우는 표시되지 않으니 한 번 더 읽어 주세요" 안내): 사진을 인식하면 신뢰도 70 미만인 단어가 필사 내용 아래에 "잘못 읽었을 수 있는 글자예요. 누르면 본문에서 찾아 줘요." 문구와 칩으로 나타납니다. 칩을 누르면 본문에서 그 단어가 선택되고 입력칸이 그 위치로 스크롤되며(다른 단어의 일부가 아닌 따로 쓰인 위치를 먼저 찾고, 같은 칩을 다시 누르면 다음 위치), 본문에서 고쳐 사라진 단어의 칩은 빠집니다. 이어 붙이기를 하면 목록이 누적되고 바꾸기·전체 지우기를 하면 새로 만들거나 비워집니다. 글자 하나가 비슷한 글자로 바뀐 오류(예: 도구→노구)는 표시되지 않는다는 안내가 함께 보입니다. 글자·숫자가 없는 기호와 한 글자짜리 한글은 목록에서 뺍니다. 사진 한 장에서 확인할 단어가 11개 이상이면 그 사진의 칩은 만들지 않고 "글자가 많이 깨졌어요. 인식할 부분을 더 좁히거나, 책을 평평하게 펴서 다시 찍거나, 폰의 글자 복사를 써 보세요." 안내를 보입니다. 이어 붙이는 중이라 앞서 만든 칩이 있으면 그 칩은 그대로 두고 "방금 사진은 글자가 많이 깨져서 확인 목록을 만들지 않았어요. …"로 안내합니다. 이 안내는 다음 사진 인식이나 전체 지우기 때 사라집니다. 목록은 저장하지 않습니다.
- 본문 입력칸은 높이가 화면의 약 40%(최소 약 192px)로 고정되고 긴 글은 입력칸 안에서 스크롤됩니다. 확인 칩(안내 문구 포함)은 한 줄 가로 스크롤 띠이며, 필사 내용 영역("필사 내용" 제목부터 글자 수 표시까지) 안에서는 화면을 위아래로 스크롤해도 화면 위·아래 가장자리에 붙어 따라오고(`sticky`), 이 영역을 벗어나면(사진·종류 쪽, 메모·저장 쪽) 함께 밀려나 보이지 않습니다.
- 본문 입력(인식 결과 또는 직접 입력, 인식하는 동안에는 입력칸이 잠겨 쓸 수 없음), "전체 지우기"(내용이 있을 때만 보이며 확인 창을 거침), 후처리 다시 적용("줄바꿈 다시 정리", 내용이 마지막 사진 한 장의 인식 결과로만 이루어졌을 때만 보임), "메모 (선택)"(안내: 이 필사에 남길 말), "기록한 날"(날짜 칸, 새 필사는 오늘·수정은 원래 날짜가 기본값, 오늘까지만 선택, 시각은 유지하고 날짜만 바뀜, 달력·통계가 이 날짜를 기준으로 함), "저장하기"(본문이 비거나 한도를 넘으면 비활성)
- 입력 한도: 본문 5,000자, 메모 500자, 책 제목 100자, 저자 50자, 출판사 50자, 사진 10MB. 글자 수는 "N / 5,000자"로 표시하며, 넘으면 빨간색과 "N자를 줄여 주세요" 문구가 표시됩니다. 사진이 10MB를 넘으면 안내 문구를 보여 주고 불러오지 않습니다. 책 제목·저자는 입력칸에서 한도를 넘는 글자가 입력되지 않으며(등록·수정 모두), 한도의 80%(제목 80자, 저자 40자)부터 입력칸 아래에 "N / 100자"처럼 작게 보입니다. 이미 100자를 넘게 등록된 제목은 그대로 보이고 수정할 때만 줄여야 합니다.

### 기록 탭 (달력 · 통계)
달력과 통계를 오가도 보던 달·날짜·통계 탭이 그대로 유지됩니다(달력과 통계를 함께 띄워 두고 안 보이는 쪽을 숨깁니다). 다른 하단 탭(책장 등)으로 나갔다 오면 처음 상태(이번 달·오늘)로 돌아옵니다.
기록 탭을 열어 둔 채 자정을 넘기면(또는 앱 화면에 다시 돌아왔을 때 날짜가 바뀌어 있으면) 달력·통계를 오늘 기준으로 새로 엽니다. 필사 입력 화면은 영향을 받지 않습니다.
- 위쪽 전환: 달력 / 통계
- 날짜별 필사 목록(달력·통계 공통): 글이 길면 내용 4줄·메모 2줄까지만 보여 주고 "더 보기/접기"로 펼칩니다. 한 번에 5개씩 보여 주며 5개를 넘으면 아래에 페이지 번호가 나옵니다. 번호를 눌러도 화면은 맨 위로 올라가지 않고, 날짜(또는 통계의 선택한 날)를 바꾸면 처음 페이지로 돌아갑니다.
- 독서 달력: 월 이동(‹ ›, 이번 달에서는 › 가 비활성이고 연·월 고르기 창도 미래 달을 고를 수 없음), 가운데 "2026년 11월 ▾" 제목을 누르면 연·월 고르기 창이 열림(위 ‹ ›로 연도 이동, 12개 월 칸을 누르면 그 달로 이동하고 창이 닫힘, 필사가 있는 달에는 작은 점, "이번 달"·"닫기" 버튼), 날짜 칸 진하기(필사 1·2·3개 이상) 또는 점, 책을 완독한 날은 칸 오른쪽 위에 작은 ✓(완독 날짜가 있는 완독 책만, 통계와 같은 기준; 표시가 있는 달에는 달력 아래에 "✓ 표시는 책을 완독한 날이에요." 안내, 위 요약에는 "· 완독 N권"), 날짜를 누르면 그날 필사 목록(책 제목·종류·페이지·내용·메모)과 완독한 책 이름("✓ 완독: 제목"), "설정"(한 주 시작·표시, 취소/저장). 달력 화면에는 내려받기 버튼과 안내 문구를 두지 않음(화면을 깔끔하게 유지). 내용 내려받기는 설정 탭의 "데이터" 카드 안 "읽기용 문서로 내려받기"(형식 마크다운/텍스트, 범위 전체·올해·이번 달·직접 고르기(월 단위, 연·월 고르기 창에서 미래 달 선택 불가), "문서로 내려받기" 버튼, "읽고 공유하는 용도라서 이 파일로는 기록을 되살릴 수 없어요" 안내, 형식은 기억하고 범위는 열 때마다 "이번 달"). 파일은 필사한 날과 완독한 날을 날짜별로 묶은 .md/.txt이며(완독한 날에는 날짜 제목 아래에 "✓ 완독: 제목" 한 줄이 들어가고, 완독만 한 날도 날짜 항목으로 들어감. 위 요약은 "필사한 날 N일 · 필사 N개 · 완독 N권"이며 "필사한 날"은 필사가 있는 날만 셈, 완독이 없으면 "완독" 문구는 생략). 월 이동·요약·요일·날짜 격자(와 완독 안내 한 줄)는 흰 카드 하나로 묶어 보여 주고, 필사 없는 날은 빈 화면 카드로 보여 줌
- 통계: 위 카드 3칸(필사·글자 수·완독한 책 — 완독 날짜가 있는 책만 세며 목표·월간·연간과 같은 기준이고 세 카드 모두 전체 기간이라 카드 위에 작은 소제목 "전체 기간"을 보여 줌), 그 아래 "2026년 완독 목표" 카드(목표가 없으면 "목표 정하기" 링크와 안내 문구, 있으면 "완독 수 / 목표권"·퍼센트·진행 막대·"N권 남았어요"(이루면 "목표를 이뤘어요!")·"고치기" 링크; 제목에 연도가 있어 올해만 센다는 것을 알 수 있고, 위 카드는 "전체 기간" 소제목으로 구분함; 누르면 숫자 칸과 저장·취소·목표 없애기), 아래 탭은 일간·월간·연간 통계. 일간 통계(종류 필터·한 주 줄·선택한 날 요약과 완독한 책(필사 수·글자 수 카드 아래에 "✓ 완독한 책" 카드로 제목을 보여 줌, 달력과 같은 기준)과 목록, 가운데 "2026년 11월 ▾" 제목을 누르면 달력과 같은 연·월 고르기 창이 열리고 달을 고르면 그 달 1일이 있는 주로 이동하며 이번 달은 오늘로 이동, 미래는 볼 수 없어 오늘이 든 주에서는 › 가 비활성이고 오늘 이후 날짜와 다음 달 이후는 흐리게 눌리지 않음, 지난 주에서 › 로 이동한 날이 오늘보다 늦으면 오늘이 선택됨), 월간 통계(종류 필터·"2026년 11월 ▾" 제목으로 연·월 고르기·이번 달에서는 › 가 비활성이고 연·월 고르기 창에서도 미래 달은 눌리지 않음·카드 4칸(이 달 필사·글자 수·필사한 날·완독한 책)·가장 많이 필사한 날·날짜별 필사 개수 막대, 막대를 누르면 그날의 일간 통계로 이동하고 오늘 이후 날짜의 막대는 눌리지 않음), 연간 통계(요약 카드·월별 막대, 월별 막대나 아래 월 숫자를 누르면 그 달의 월간 통계로 이동(올해의 아직 오지 않은 달은 눌리지 않음), 가운데 "2026년 ▾" 제목을 누르면 올해 기준 과거 5년과 올해(6칸)를 보여 주는 연도 고르기 창이 열림: 보는 해는 파란 채움·올해는 회색 테두리·필사가 있는 해는 점, "올해"·"닫기" 버튼, › 는 올해에서, ‹ 는 5년 전에서 비활성). 카드 구성은 달력과 맞춤: 일간은 월 이동과 한 주 날짜 줄을 카드 하나로 묶고(연·월 고르기 창도 그 안에 열림), 월간·연간은 이동 줄은 카드 없이 두고 막대 그래프와 설명 문구를 카드 하나로 묶음(설명 문구는 월간 "막대 하나는 하루예요. 누르면 일간 통계로 이동해요.", 연간 "막대 하나는 한 달이에요. 누르면 월간 통계로 이동해요.")
- 실패 문구: 글자를 못 찾았을 때와 인식 실패 때 각각 다음 행동을 안내

### 즐겨찾기
- ★한 필사를 최신순으로 5개씩 목록으로 나눠 표시(글이 4줄을 넘으면 "더 보기/접기"로 펼침), 선택 모드로 여러 개 해제(필사 내용은 유지)
- 위쪽 버튼: "선택", "전체 즐겨찾기 해제"(회색 테두리·진한 회색 글씨, 삭제가 아니라 별표만 풀기 때문에 빨강을 쓰지 않음). 선택 모드에서는 "N개 선택", "전체 선택/전체 선택 해제" 링크, "선택한 N개 해제" 버튼(선택이 없으면 비활성, 같은 회색 스타일), "취소"가 나옵니다. 책장 편집 모드의 "전체 선택/전체 해제"(선택을 푸는 뜻)와 글자가 헷갈리지 않게 즐겨찾기 쪽 문구에는 대상을 적었습니다.
- 즐겨찾기가 없으면 위의 빈 화면 카드("책의 필사 옆 ☆를 눌러 보세요.")만 보입니다.

### 설정
- 제목 아래 안내: "항목 이름을 누르면 펼치고 접을 수 있어요."
- 접고 펼 수 있는 카드 5개(글자 설정·화면 구성 편집·데이터·정보·사용 방법). 처음에는 "화면 구성 편집"만 펼침. 접힌 카드는 제목 옆에 현재 선택을 요약
- **글자 설정**: 글자 크기 4단계, 화면 글꼴 3종, 필사 본문 글꼴 5종, 미리보기
- **화면 구성 편집**: 위쪽에 고정되는 미리보기 상자(이 카드 안에서만 고정되며, 카드 끝을 지나면 함께 밀려나 사라집니다. 아래 탭 줄은 실제 하단 탭과 같게 책장·즐겨찾기·기록·설정 4개를 아이콘과 함께 보여 주고, 선택한 책장만 또렷하게 하며 나머지는 흐리게 함) + 항목별 한 줄 설명
  - 전체 색 테마(라이트·다크·세피아·기기 설정), 포인트 색(먹색·보라·파랑)
  - 표지 색(파랑·보라·핑크·책마다, 설명 문구에 "책마다는 책 제목에 따라 여러 색이 섞여 나와요" 안내), 표지 색 밝기(자동·1·2·3단계), 표지 글자

## 3. 시각 규칙
- 글꼴: 제목·필사 본문은 "필사 본문 글꼴", 나머지는 "화면 글꼴"
- 글자 크기: 제목 `text-2xl`, 본문 `text-base`, 보조 `text-sm`, 메타 `text-xs` (기본 18px 기준, 설정으로 변경. 작게 16px · 보통 18px · 크게 20px · 아주 크게 22px). 필사 본문 글꼴이 나눔손글씨 펜이면 제목·필사 본문에 1.25배 보정이 곱해집니다
- 줄바꿈: 한글은 띄어쓰기 단위로 줄을 바꿉니다(`word-break: keep-all`). 한 단어가 한 줄보다 길 때만 글자 중간에서 끊습니다(`overflow-wrap: anywhere`).
- 색: 배경·글자는 테마 변수, 버튼·선택·활성 탭은 포인트 색, 표지는 파스텔(어느 테마에서나 밝은 파스텔 유지)
- 회색 점: 진한 회색(세피아는 갈색 톤) + 연한 테두리

## 4. 접근성·사용성 점검 기준
- 입력창 글자 16px 이상(iOS 자동 확대 방지)
- 버튼 최소 높이 약 34px 이상, 한 줄에 4개를 놓는 버튼은 짧은 이름 사용
- 색만으로 뜻을 전달하지 않기(상태는 배지 글자로 표시)
- 다크·세피아에서 모든 글자가 읽히는지(상태 배지는 고정 색 칩)
