# 화면 명세 (ui-spec.md)

> 작성: AI 초안 / 확인: 개발자(사용성, 접근성, 화면 요구사항)

## 1. 화면 흐름
```
하단 탭 ── 책장 ──(책 선택)── 책 상세 ──(📷 필사 추가하기 / 필사 수정)── 필사 추가·수정
       ├─ 즐겨찾기 (★ 모음, 선택 모드로 여러 개 해제)
       ├─ 기록 (달력 · 통계)
       └─ 설정 (글자 설정 · 화면 구성 편집 · 데이터 · 정보 · 사용 방법)
```
상세·필사 화면에서는 하단 탭이 숨겨지고, "← 책 목록"(상세) 또는 "← 취소"(필사)로 한 단계 돌아가거나 "첫 화면"으로 책장에 바로 돌아갑니다.
책장 화면 위에는 백업 알림 띠가 필요할 때만 표시됩니다. ✕로 닫으면 7일 동안 백업 문구가 숨겨지고, 저장 공간 80% 이상 경고는 닫을 수 없이 계속 표시됩니다(경고만 있을 때는 ✕가 없습니다). 삭제 직후에는 7초 동안 "되돌리기" 안내가 아래쪽에 표시됩니다.

## 2. 화면별 구성

### 책장
- 상단: 앱 이름, "+ 책 등록", "편집", 안내 문구
- 등록 폼(열었을 때): 제목(필수), 저자, "등록하기"
- 필터(전체·읽고 싶은·읽는 중·완독·중단 + 개수), 정렬(최근 필사순·등록순·제목순·저자순·필사 많은 순)
- 책 카드(한 줄 2~3열): 파스텔 표지, 회색 점(3일 안에 필사한 책), 상태 배지, 필사 개수·마지막 필사
- 표지 글자: 제목 전체 / 제목 + 저자 / 없음. 없음이면 표지 아래에 제목 표시
- 편집 모드: 카드를 눌러 선택(체크 표시), "전체 선택/전체 해제" 줄, 하단 "선택한 책 N권 삭제"(확인 창)
- 빈 상태: "첫 책을 등록해 보세요" 안내와 "+ 책 등록" 버튼, 3단계 안내(책 등록 › 사진 찍기 › 고쳐서 저장)

### 책 상세
- 위쪽: "← 책 목록"(책장으로), "첫 화면"(책장으로 바로 이동)
- 책 정보(제목, 저자), 상태 변경, 필사 종류 필터, 필사 카드(본문, 메모, 종류, 페이지, ☆/★, 복사, 수정·삭제), 목록 나누기, 내보내기, 필사 전체 삭제(삭제 후 7초 동안 되돌리기 가능)
- 하단 고정 버튼: "📷 필사 추가하기"

### 필사 추가·수정
- "📷 카메라로 촬영", "🖼 사진 불러오기" → 진행 막대(글자 인식 중 / 언어 데이터 불러오는 중)
- 위쪽: "← 취소"(책 상세로), "첫 화면"(책장으로)
- 사진 팁 두 줄: 필사할 부분만 크게·밝은 곳에서 정면으로 / 사진 속 글자는 모두 본문에 들어가니 페이지 숫자·머리글은 지우고 페이지 칸에 직접 입력
- 종류 칩(책 문장 · 내 글, 둘 다 켜기 가능, 안 켜면 미분류) 오른쪽에 페이지 칸
- 본문 입력(인식 결과 또는 직접 입력), 후처리 다시 적용, "메모 (선택)"(안내: 이 필사에 남길 말), "저장하기"(본문이 비거나 한도를 넘으면 비활성)
- 입력 한도: 본문 5,000자, 메모 500자, 사진 10MB. 글자 수는 "N / 5,000자"로 표시하며, 넘으면 빨간색과 "N자를 줄여 주세요" 문구가 표시됩니다. 사진이 10MB를 넘으면 안내 문구를 보여 주고 불러오지 않습니다.

### 기록 탭 (달력 · 통계)
- 위쪽 전환: 달력 / 통계
- 독서 달력: 월 이동, 날짜 칸 진하기(필사 1·2·3개 이상) 또는 점, 날짜를 누르면 그날 필사 목록(책 제목·종류·페이지·내용·메모), "설정"(한 주 시작·표시·내려받기 범위·형식, 취소/저장), "내려받기"
- 통계: 위 카드 3칸(필사·글자 수·완독한 책), 일간 통계(종류 필터·한 주 줄·선택한 날 요약과 목록), 연간 통계(요약 카드·월별 막대)
- 실패 문구: 글자를 못 찾았을 때와 인식 실패 때 각각 다음 행동을 안내

### 즐겨찾기
- ★한 필사를 최신순으로 3개씩 목록으로 나눠 표시, 선택 모드로 여러 개 해제(필사 내용은 유지)

### 설정
- 제목 아래 안내: "항목 이름을 누르면 펼치고 접을 수 있어요"
- 접고 펼 수 있는 카드 5개(글자 설정·화면 구성 편집·데이터·정보·사용 방법). 처음에는 "화면 구성 편집"만 펼침. 접힌 카드는 제목 옆에 현재 선택을 요약
- **글자 설정**: 글자 크기 4단계, 화면 글꼴 3종, 필사 본문 글꼴 5종, 미리보기
- **화면 구성 편집**: 위쪽에 고정되는 미리보기 상자 + 항목별 한 줄 설명
  - 전체 색 테마(라이트·다크·세피아·기기 설정), 포인트 색(먹색·보라·파랑)
  - 표지 색(파랑·보라·핑크·책마다), 표지 색 밝기(자동·1·2·3단계), 표지 글자
  - 한 줄 카드 수(2·3열)와 모서리(각지게·둥글게)는 한 줄에 나란히
  - 표시 항목(회색 점, 상태 배지)
- **데이터**: 저장 공간 사용률과 마지막 백업 날짜 표시, 내보내기(백업 시각 기록), 가져오기(20MB 초과 파일은 거절), 결과 문구, 모든 기록 삭제(빨간 버튼, 되돌리기 없음)
- **정보**: 개인정보 안내, 저작권 안내, 오픈소스 라이선스
- **사용 방법**: 8개 항목을 눌러 펼침(8번은 설정 항목 접고 펼치기)

## 3. 시각 규칙
- 글꼴: 제목·필사 본문은 "필사 본문 글꼴", 나머지는 "화면 글꼴"
- 글자 크기: 제목 `text-2xl`, 본문 `text-base`, 보조 `text-sm`, 메타 `text-xs` (기본 18px 기준, 설정으로 변경. 작게 16px · 보통 18px · 크게 20px · 아주 크게 22px)
- 색: 배경·글자는 테마 변수, 버튼·선택·활성 탭은 포인트 색, 표지는 파스텔(어느 테마에서나 밝은 파스텔 유지)
- 회색 점: 진한 회색(세피아는 갈색 톤) + 연한 테두리

## 4. 접근성·사용성 점검 기준
- 입력창 글자 16px 이상(iOS 자동 확대 방지)
- 버튼 최소 높이 약 34px 이상, 한 줄에 4개를 놓는 버튼은 짧은 이름 사용
- 색만으로 뜻을 전달하지 않기(상태는 배지 글자로 표시)
- 다크·세피아에서 모든 글자가 읽히는지(상태 배지는 고정 색 칩)

## 5. 개발자가 반드시 확인할 것
- [ ] 큰 글자(아주 크게)와 손글씨 글꼴에서 레이아웃이 깨지는 화면이 없는가
- [ ] 3열에서 긴 제목이 표지 안에서 읽을 만한가
- [ ] 다크·세피아에서 필사 추가·상세 화면의 모든 요소 대비가 충분한가
- [ ] 설정 미리보기 상자가 작은 화면에서 너무 많은 공간을 차지하지 않는가
